# Costra · 微信小程序审核自查清单

> Refs: COSTRA-050, 官方审核指引 <https://developers.weixin.qq.com/miniprogram/product/>  
> 首次提交审核前、每次版本提审前**逐项勾选**；一项未通过禁止提审。

---

## A. 类目与主体合规

- [ ] 小程序类目与实际功能一致（记账属于"工具"类，勿混入"金融"敏感类目）
  - 参考：<https://developers.weixin.qq.com/miniprogram/product/material/>
- [ ] 账号主体类型与功能定位一致（企业主体 vs 个人主体能做的功能范围不同）
- [ ] 小程序名称、Logo、简介无商标侵权 / 无夸大宣传
- [ ] 服务范围地域合规（如涉及特定省份业务需补说明）

## B. 用户隐私与信息收集（审核高频驳回点）

- [ ] 已提交 **《用户隐私保护指引》**（公众平台"设置 → 隐私设置 → 用户隐私保护指引"）
  - 所有收集的 API：`wx.login` / `wx.getUserProfile`（已废弃）/ 头像昵称填写 / `wx.requestSubscribeMessage`
- [ ] **隐私弹窗**（2023-09 后新规）：小程序首次打开调用任一隐私接口前，出现同意弹窗；未同意不调用接口
  - `app.json` 配置 `"__usePrivacyCheck__": true`（若使用官方隐私组件）或自行实现
  - 参考：<https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/>
- [ ] 隐私指引内容与代码实际行为一致（列出的字段、使用目的、共享规则必须真实）
- [ ] `miniprogram/pages-family/privacy/index` 的真实条款已由法务/Human 审核通过，替换占位 TODO
- [ ] 不在用户未授权前静默调用 `wx.login`（可调，但不得将 openId 与 userInfo 关联用于画像）

## C. 头像昵称新规（2023-09 起）

- [ ] 不再使用 `wx.getUserProfile`（已废弃）
- [ ] 使用 `<button open-type="chooseAvatar">` 或头像昵称填写能力
  - 参考：<https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/userProfile.html>
- [ ] 头像上传走微信默认素材或走自建 CDN（需在隐私指引中声明）
- [ ] 昵称输入禁止预填"微信昵称"（需由用户主动输入）

## D. 订阅消息

- [ ] 模板 ID ×3 已在微信公众平台申请并审核通过
  - 预算预警 / 家庭邀请 / 周报摘要（对齐 ADR-0004 §5）
- [ ] 发送内容与模板用途一致（不得借模板发送广告）
- [ ] 不"一次性授权反复发送"（每次发送需在合理场景下单独获授权）
- [ ] 后端下发调用 `sendMessage` 有完整日志，保留 90 天备查

## E. 敏感信息与金融属性

- [ ] **不涉及**用户资金托管 / 代收代付 / 借贷（记账仅为用户本地数据视图）
- [ ] 不收集身份证号、银行卡号；若未来收集需主体资质 + 补充协议
- [ ] 支付相关（若未来接入）：必须走微信支付官方 API，不得自建收银台
- [ ] 账本数据的"导出"功能若涉及 PII，需二次确认 + 水印

## F. 内容与功能规范

- [ ] 无色情、暴力、赌博、博彩、医疗广告、代购代刷、虚拟资产等禁止内容
- [ ] 无外部链接跳转（微信小程序不允许 `web-view` 指向未在业务域名白名单的 URL）
- [ ] 分享卡片文案符合"诚信、真实、无诱导"原则；不得使用"点击领取" "必得" 等诱导词
- [ ] 新功能若有 A/B 变体，所有变体都需通过审核（`share_card_variant` Flag 下两套卡片均需送审）

## G. 基础库兼容与稳定性

- [ ] 最低基础库 **2.32.3**（对齐 PRD NFR）
- [ ] 在最新三个微信版本真机通过冒烟（对应 `docs/qa/smoke-cases.md`）
- [ ] 冷启 TTI ≤ 2s（见 NFR）
- [ ] 无明显性能劣化 / 崩溃率 < 0.3%（待 Sentry 接入后量化）

## H. 体积与网络

- [ ] 主包体积 ≤ **1.5MB**，总包 ≤ **16MB**（`npm run mp:build:check`）
- [ ] `request` 域名全部在"服务器域名"白名单中（生产域名提前配置并备案）
- [ ] 不访问未备案域名；本地开发的 `127.0.0.1` / `localhost` 仅在 `__wxConfig.envVersion === 'develop'` 下启用

## I. 客服与问题处理

- [ ] 客服入口可达（公众平台绑定客服账号或提供帮助页邮箱）
- [ ] 帮助页 / FAQ 提供基本使用说明
- [ ] 紧急问题 SLA：P0 阻断 → 24h 内热修或回滚

## J. 合规申报（如适用）

- [ ] 若日活目标超 50 万或涉 PII，参照《生成合成类 / 信息服务》相关申报要求
- [ ] 数据出境：默认不出境；若接入海外服务需出境评估

## K. 审核提交清单

- [ ] 版本号符合 `vX.Y.Z`（由 `mp-release.yml` 强校验）
- [ ] 版本描述清晰列出本次变更（面向审核员 + 用户，两段式）
- [ ] 测试账号（用户名 / 密码 / 家庭 demo token）可用 ≥ 7 天
- [ ] 必需截图：首页、记一笔、我的、家庭邀请、隐私指引
- [ ] 隐私指引链接可点开
- [ ] **发布前灰度**：10% → 观察 48h → 100%（由 `mp-release.yml` + 微信公众平台"分阶段发布"协同）

## L. 常见驳回点（本项目高风险）

| 驳回点 | 预防措施 |
|---|---|
| 隐私指引与代码不一致 | 每次新增 API 调用必须同步更新指引；CI 可加 `grep` 规则（Sprint-2） |
| 订阅消息场景不符 | 严格按 ADR-0004 §5 的触发规则，不在启动页批量拉取授权 |
| 分享诱导 | `docs/design/share-cards/*` 文案初稿已规避，提审前 QA 复核 |
| 服务类目不符 | 若未来加"AI 助手记账"类功能需变更类目，重新提审 |
| 账本数据声称"云存储"但未备案 | 文案统一为"本地保存 + 可选云同步"，云同步域名必须备案 |

## 提审操作

```bash
# 1. 确认本清单全部勾选
# 2. 本地跑体积与冒烟
npm run mp:build:check

# 3. 合入 main，打 tag
git tag v0.1.0
git push origin v0.1.0
# → 触发 .github/workflows/mp-release.yml（需 production env 审批）
# → 上传到微信后台待审核

# 4. 微信公众平台 → 版本管理 → 提交审核
```
