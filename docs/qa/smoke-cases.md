# Costra · 冒烟用例集 v0.1

> Refs: COSTRA-050, PRD Epic-A~G, `docs/qa/test-strategy.md`  
> 每次发布前**必须**全部通过；任意一条失败 → 禁止发版。

---

## 通用约定

- **前置**：体验版或 dev 构建已安装；测试账号 A（主记账人）、B（家庭成员）已准备
- **环境**：iOS + Android 各一台（或模拟器），微信近 1 年版本
- **基础库**：2.32.3
- **失败记录**：任何失败请在 PR / Issue 中贴截图 + 复现步骤

**严重度**：P0=阻断发版 / P1=需当日修 / P2=下 Sprint 修 / P3=积压

---

## S-001 冷启动与首屏 TTI

- **前置**：杀掉微信进程，重新打开
- **步骤**：
  1. 点击小程序图标
  2. 计时从点击到首屏 `home` 可点击
- **期望**：TTI ≤ **2s**（见 PRD NFR）
- **严重度**：P1

## S-002 登录闭环（首次）

- **前置**：未登录态（清除小程序存储）
- **步骤**：
  1. 启动 → 自动进入 `pages/login`
  2. 点击"一键微信登录"
  3. 允许获取用户信息
- **期望**：
  - 2s 内跳转 `home`
  - `wx.storage.costra_session_v1` 有有效 Token
  - 冷启再打开直接进 `home`
- **严重度**：**P0**

## S-003 登录失败重试

- **前置**：离线或 Mock 网络超时
- **步骤**：登录页点击登录
- **期望**：错误提示"登录失败，请重试"，可再次点击；不崩溃
- **严重度**：P1

## S-004 Token 过期自动续签

- **前置**：手动把 `wx.storage` 中 Token `exp` 改为过去时间
- **步骤**：从 `home` 下拉刷新
- **期望**：请求层自动调 `POST /v1/auth/refresh`；对业务 UI 无感（对照 ADR-0004 §3）
- **严重度**：P1

## S-005 记一笔 · 支出全流程

- **前置**：已登录
- **步骤**：
  1. `home` 点右下角 `+`
  2. 选"支出"，输入 `12.34`
  3. 选分类（建议默认"餐饮"）
  4. 备注"测试"
  5. 保存
- **期望**：
  - Toast "已记录"
  - `home` 本月支出增加 12.34
  - 数据库（若能查）对应 `amount_cents = 1234`，`currency='CNY'`（对照 ADR-0004 §4）
- **严重度**：**P0**

## S-006 记一笔 · 金额边界

- **前置**：记一笔页
- **数据驱动**：
  - `0` → 拒绝，提示"请输入金额"
  - `0.005` → 记为 `0` 分（截断），UI 显示"0.00"（或校验拒绝；以 ADR-0004 为准）
  - `999999999.99` → 记录成功；显示千分位
  - 负数 → 输入过滤禁止
- **严重度**：P1

## S-007 离线记一笔 · 本地兜底

- **前置**：开启飞行模式
- **步骤**：记一笔保存
- **期望**：
  - Toast "已记录"（本地排队）
  - 网络恢复后自动上行同步（`services/sync.ts`），服务端幂等不重复
- **严重度**：P1

## S-008 流水筛选 · 日期 + 类型

- **前置**：账本有跨月数据 ≥ 20 笔
- **步骤**：
  1. 进入"最近记录" / 流水页
  2. 选"本月 + 支出"
- **期望**：列表正确过滤，数量、汇总金额匹配
- **严重度**：P2

## S-009 家庭邀请 · 生成分享卡片

- **前置**：A 账号已登录且属于某家庭
- **步骤**：`我的` → `家庭共享` → 生成邀请
- **期望**：
  - 产出分享卡片（设计来自 `docs/design/share-cards/family-invite.md`）
  - 含 AppID 深链接；卡片含 token（有时效）
- **严重度**：P1

## S-010 家庭邀请 · 被邀请加入

- **前置**：A 刚生成邀请卡；B 账号已登录，尚未在 A 的家庭
- **步骤**：B 扫码 / 点击分享卡片
- **期望**：
  - B 跳转入家庭确认页
  - 点击"加入"后，A/B 双方的家庭成员列表更新
  - 对账本的账目权限按角色生效（主记账 / 成员）
- **严重度**：**P0**

## S-011 订阅消息 · 授权弹窗

- **前置**：首次触发需要订阅消息的操作（如"预算接近阈值")
- **步骤**：点击关键操作，观察订阅消息弹窗
- **期望**：
  - 弹窗出现；选"允许"后，本地记录授权态
  - 拒绝后，下次按 ADR-0004 §5 的重入规则再提示（非每次都弹）
- **严重度**：P1

## S-012 订阅消息 · 实际下发

- **前置**：S-011 已授权；触发条件满足（如预算 80%）
- **步骤**：触发条件
- **期望**：微信收到订阅消息，模板字段与 `docs/design/flows/budget-subscribe-msg.md` 一致
- **严重度**：P1

## S-013 主包体积红线

- **前置**：CI `pr-check.yml` 的 size-check 步骤
- **步骤**：跑 `npm run mp:build:check`
- **期望**：主包 ≤ 1.5MB；总包 ≤ 16MB（对照 ADR-0004 §2）
- **严重度**：P1

## S-014 API 超时与错误提示

- **前置**：Mock 后端返回 500 或延迟 >10s
- **步骤**：触发记一笔提交
- **期望**：
  - 5s 内给出"网络开小差"提示
  - 本地兜底不丢数据（同 S-007）
  - 不崩溃、不无限 loading
- **严重度**：P1

## S-015 冷启 + 分包预加载

- **前置**：杀后重启
- **步骤**：从 `home` 点击"我的"
- **期望**：切换到 `mine` 流畅（`family` 分包已预加载，见 `miniprogram/app.json` `preloadRule`）
- **严重度**：P2

## S-016 统计页占位

- **前置**：已登录
- **步骤**：`我的` → `统计报表`
- **期望**：跳转到 `pages-stat/month/index`；占位文案正确展示；不崩溃
- **严重度**：P2

## S-017 隐私指引页

- **前置**：登录页
- **步骤**：点击底部"《隐私保护指引》"
- **期望**：跳转到 `pages-family/privacy/index`；内容可读；返回正常
- **严重度**：P1（审核前必须替换为真实条款，见 `docs/qa/wechat-review-checklist.md`）
