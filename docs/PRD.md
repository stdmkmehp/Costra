## 1. 产品定位

### 1.1 产品一句话
**Costra** 是面向家庭的云端共享记账微信小程序：一个家庭，一本账，记完即同步，查得出、管得住。

### 1.2 目标用户画像
| 画像 | 人群 | 核心诉求 | MVP 覆盖度 |
|---|---|---|---|
| P1 家庭主力记账者（25~40 岁） | 夫妻共同财务 | 多端同步、多人协作、账户清晰 | ✅ 全量 |
| P2 家庭次要成员（父母/配偶） | 被邀请加入 | 低门槛记一笔、只看不改也行 | ✅ 全量 |
| P3 单人轻度记账用户 | 学生/单身 | 即开即用、无需注册 | ✅ 全量（家庭功能可选） |

### 1.3 北极星指标（引用章程）
| 指标 | 目标 | 衡量口径 |
|---|---|---|
| D1 留存 | ≥ 40% | 登录日次日再次打开 |
| 家庭激活率 | ≥ 15% | 创建家庭且成员 ≥ 3 |
| 月人均记账次数 | ≥ 30 | 活跃用户月总流水条数 / 活跃用户数 |
| 首屏可交互（P75） | ≤ 2s | 小程序后台「性能」面板 |

## 4. 功能需求（Epic / Story / AC）

> 每个 Story 的 AC 采用 **Given-When-Then** 格式，且每条至少覆盖 `正常路径 / 异常路径 / 弱网 / 权限拒绝` 中 2 个以上。
> 完整 Story ID 与估点以 `.team/backlog.json` 为准，本文档仅展开 MVP 范围内的 Story。

### Epic-A 账号体系（P0）

#### COSTRA-101 微信登录（`wx.login` + `code2Session`）
**用户故事**：作为新用户，我打开小程序即可通过微信完成登录，无需额外注册。

**关键流程**：
1. 小程序启动 → `wx.login` 获取 `code` → 调 `POST /v1/auth/wechat/login`。
2. 服务端用 `code` + `appid` + `appsecret` 调微信 `code2Session` → 拿到 `openid` / `unionid` / `session_key`。
3. 服务端创建/更新 user → 下发业务 JWT（access + refresh），**`session_key` 绝不下发**。
4. 小程序存 Token 至 `wx.storage` key=`__costra_token_v1`。

**AC**：
- **AC-1**（正常）：新用户首次登录成功后 5s 内跳转首页，DB user 表 `wx_openid` 唯一，`session_key` 只存在服务端 Redis。
- **AC-2**（老用户）：已有账号再次登录，返回同一 `user_id`，不重复建号。
- **AC-3**（弱网）：登录请求超时 8s 提示"网络不稳定，请重试"，不进入白屏死局。
- **AC-4**（隐私）：首次登录前必须弹 `wx.requirePrivacyAuthorize`，拒绝则只保留只读演示账号（不可同步）。

#### COSTRA-102 手机号绑定（可选）
**AC**：
- **AC-1**：用户点"绑定手机号"→ 使用 `<button open-type="getPhoneNumber">` 触发 → 服务端解密 `encryptedData`/`iv` 并写 `users.phone`。
- **AC-2**：绑定失败（解密错/非本 session）返回 4001 并提示用户刷新重试；未绑定不影响 MVP 核心功能。
- **AC-3**：一个手机号至多绑定一个 openid；冲突时提示"该号码已绑定其他账号，请联系客服"。

#### COSTRA-103 业务 Token 鉴权 + 刷新
**AC**：
- **AC-1**：access token 有效期 2h，refresh token 30 天；过期 5 分钟前静默刷新。
- **AC-2**：refresh 也过期 → 回到登录页重新 `wx.login`。
- **AC-3**：Token 不得出现在日志/URL，仅 Header `Authorization: Bearer <token>`。

### Epic-B 单人记账（P0）

#### COSTRA-111 资金账户 CRUD
**AC**：
- **AC-1**：账户字段包含 `name / type(现金/银行卡/微信/支付宝/其他) / initial_balance / currency(CNY 默认) / archived`。
- **AC-2**：账户删除需先校验"该账户无流水"或转移流水，前端弹二次确认。
- **AC-3**：金额使用 `decimal.js` 存储与展示，禁止 `Number`。

#### COSTRA-112 分类管理 + 图标
**AC**：
- **AC-1**：系统预设分类 ≥ 20 条（餐饮/交通/购物/住房/娱乐…），用户可增/改/排序/归档。
- **AC-2**：分类图标取自 WeUI 内置 + 自定义图标上传（CDN，≤ 100KB，后续做）。

#### COSTRA-113 记一笔（收入/支出/转账）
**核心页**：`pages/index/add-transaction`。

**AC**：
- **AC-1**（支出）：金额 > 0、账户必选、分类必选、发生日期默认今日、可加备注；提交后流水列表立刻可见（乐观更新）。
- **AC-2**（收入）：同上，类型=income。
- **AC-3**（转账）：两个账户不能相同；转账不进入支出/收入统计。
- **AC-4**（离线）：无网也能保存 → 写入本地队列 → 联网后自动上传；本地状态以"小云朵"图标提示。
- **AC-5**：单笔保存操作端到端 ≤ 300ms（有网）。

#### COSTRA-114 流水列表（分页 + 筛选）
**AC**：
- **AC-1**：支持按"账户 / 分类 / 时间范围 / 类型"筛选，下拉刷新 + 分页（20 条/页）。
- **AC-2**：空态有引导插画与"记第一笔"按钮。
- **AC-3**：列表滚动首屏 FPS ≥ 50；长列表用 `recycle-view` 或分包内按月分组。

### Epic-C 本地存储 + 云同步（P0）

#### COSTRA-121 wx.storage 封装 + 版本化结构（含 LRU）
**AC**：
- **AC-1**：封装 `get/set/remove` 均带 schema 版本号 `storage_v`；升级时跑 migration。
- **AC-2**：单 key ≤ 1MB、总 ≤ 10MB；流水按月分片（`transactions_202604`），LRU 淘汰 6 个月前数据。
- **AC-3**：敏感字段（Token）统一 key 前缀 `__costra_`；卸载清理有 API。

#### COSTRA-122 同步引擎（增量 + 版本号）
**AC**：
- **AC-1**：客户端维护 `last_sync_cursor`，服务端按 `updated_at + id` 增量返回，游标格式 `{ts}_{id}`。
- **AC-2**：单次同步最多 500 条；超过则分批拉取，显示进度条。
- **AC-3**：同步过程中断（网络切换/后台）可恢复，不产生重复写入（幂等键 `client_op_id`）。

#### COSTRA-123 冲突解决策略
**AC**：
- **AC-1**：默认"服务器权威"；客户端本地与服务器冲突时弹窗"保留本地 / 采用云端 / 合并"三选一。
- **AC-2**：金额字段冲突时强制弹窗，不允许静默覆盖。
- **AC-3**：冲突事件写 `audit_logs`，家庭场景可追溯。

### Epic-D 家庭共享（P1 但 MVP 必做）

#### COSTRA-201 家庭邀请码 + 微信群分享卡片
**AC**：
- **AC-1**：创建家庭生成 6 位邀请码，24h 过期，过期可一键刷新。
- **AC-2**：使用 `<button open-type="share">` 生成 5:4 微信群分享卡片（Design-Agent 出图）；分享路径 `pages/family/join?code=xxx`。
- **AC-3**：点卡片进入 → 小程序解析参数 → 登录态 OK 则直接弹"加入家庭"二次确认；未登录先走 COSTRA-101。
- **AC-4**：严禁诱导分享文案（避过审驳回），文案"一起用 Costra 记家庭账"中性表述。

#### COSTRA-202 成员角色与权限
**AC**：
- **AC-1**：角色 = `owner / admin / member / viewer`；owner 唯一，可转让不可删除自己最后一个。
- **AC-2**：viewer 只读；member 可增/改自己的流水；admin 可管理成员与分类；owner 可解散家庭。
- **AC-3**：首次查看他人流水时弹"二次同意"弹层（合规要求）。

#### COSTRA-203 实时变更推送（WebSocket + 订阅消息兜底）
**AC**：
- **AC-1**：小程序前台用 `wx.connectSocket` 接服务端 WSS，消息到达 300ms 内渲染新流水。
- **AC-2**：后台/熄屏用**订阅消息**推送"家庭成员新增流水"模板，需用户提前授权。
- **AC-3**：订阅消息模板 ≥ 3 个（见 charter §9），文案由 Design-Agent 与 PM 会签。
- **AC-4**：WebSocket 重连指数退避（1s/2s/4s/8s，封顶 30s），断连期间切本地队列不阻塞 UI。

#### COSTRA-204 审计日志
**AC**：
- **AC-1**：记录 `user_id / family_id / action / before / after / ts` 到 `audit_logs`，保留 180 天。
- **AC-2**：家庭"操作记录"页可查最近 30 天操作（分页）。

#### COSTRA-301 月度预算 + 超支提醒（订阅消息）

- **AC-2**：到期前 1 天发订阅消息提醒；到期当日自动生成一条待确认流水（用户确认后才计入统计）。

### Epic-G 上线与运营（P0）

#### COSTRA-901 隐私协议 + 类目合规 + 提交微信审核
**AC**：
- **AC-1**：小程序后台提交类目"生活服务 → 记账工具"，不触碰金融类。
- **AC-2**：完成《用户隐私保护指引》上传，`app.json` 声明 `requiredPrivateInfos`。
- **AC-3**：首次启动弹 `wx.requirePrivacyAuthorize`，拒绝后只读演示。
- **AC-4**：QA 出具"微信审核自查清单"五张签字单（功能/性能/安全/兼容/审核）。

#### COSTRA-902 分阶段发布（1% → 10% → 50% → 100%）
**AC**：
- **AC-1**：每档发布前人工闸门 G5；每档观察窗口 ≥ 24h；关键指标（JS 错误率、P75 FCP、登录成功率）不恶化方可进入下一档。
- **AC-2**：任一档出现 P0 事故 → DevOps 立即版本回退并产出 `incident report`。

#### COSTRA-903 APM + 小程序后台 JS 异常监控
**AC**：
- **AC-1**：接入微信小程序后台 JS 异常 + 自建 APM；Top5 报错每日自动推送 DevOps 日报。
- **AC-2**：关键接口（登录/记一笔/同步）P99 ≤ 800ms、错误率 ≤ 0.5%。

## 5. 非功能性需求（NFR）

| 维度 | 指标 | 验证方式 |
|---|---|---|
| 性能 | 首屏可交互 ≤ 2s（P75）；记一笔端到端 ≤ 300ms | 小程序后台性能面板 + 自建埋点 |
| 可用性 | 生产 SLA ≥ 99.9% | Prometheus 月报 |
| 体积 | 主包 ≤ 2MB，单分包 ≤ 2MB，总 ≤ 20MB | CI 体积门禁 |
| 精度 | 金额全链路 DECIMAL(18,4)/decimal.js | 单测 + 代码扫描阻断 `Number` 金额 |
| 安全 | session_key/appsecret 不下发；Token 不入 URL/日志 | 代码扫描 + 渗透自查 |
| 隐私 | 隐私指引 + 二次同意 + 家庭数据最小化 | 审核自查单 |
| 离线 | 核心"记一笔"无网可写 | QA 弱网用例 |
| 兼容 | 微信版本 ≥ 8.0.30；iOS 14+ / Android 8+ | QA 兼容矩阵 |
| 可观测 | JS 错误率日报 + 关键接口 P99 告警 | APM + AlertManager |

## 6. 数据与隐私（合规基线）

- **数据分类**：账号（openid/unionid/phone）、记账（流水/账户/分类）、家庭（成员/角色/审计）、运营（埋点）。
- **存储位置**：中国大陆地域主存储（MySQL 8 + Redis 7 + COS），**不跨境传输**。
- **最小化**：
  - 不收集昵称/头像/地理位置（MVP 内）。
  - 不收集通讯录/相册/剪贴板。
- **可撤回**：用户可在"我的→设置→注销账号"发起注销，T+7 内物理删除（审计日志保留 180 天脱敏）。
- **家庭数据**：仅本家庭成员可见；成员离开家庭后其历史流水对其他成员**保持匿名化显示**。
