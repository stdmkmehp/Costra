# 分享卡片 · 预算守卫 `budget-kept`

> **触发**：月末 T+1 自动检测「本月未超任何预算」→ 首页横幅 + 订阅消息"本月预算达成"
> **落地页**：`pages-stat/budget-kept?period=<YYYY-MM>`

---

## 视觉稿

```
┌──────────────────────────────────────────────┐
│  2025 年 3 月 · 预算达成                      │  ← caption
│                                               │
│   🛡️  这个月，钱袋守住了                     │  ← h1 28rpx
│                                               │
│   ┌─────────────┐ ┌─────────────┐             │
│   │ 预算 ￥5,000 │ │ 实际 ￥4,318 │            │
│   └─────────────┘ └─────────────┘             │
│                                               │
│   结余 ￥682 · 延续 2 个月                    │  ← body · amount.income 色
│                                               │
│                       Costra · 家庭记账 [logo]│
└──────────────────────────────────────────────┘
```

- 画布：750 × 600 rpx
- 背景：淡绿径向 `#E6F4EF` → 白；深色 `#1E2E27` → `#0A0A0A`
- "🛡️"：使用品牌自绘盾牌图标（非 emoji），确保跨设备一致

## 连击徽章（可选）

连续达成 ≥ 2 个月时，右上角显示徽章：`连击 × N`（`c-tag` 主题色 accent）。

## 文案矩阵

| 变体 | 主句型 |
|---|---|
| a | `这个月，钱袋守住了` |
| b | `<月份> 的账，稳了` |

## 接口与埋点

- `onShareAppMessage`：`?period=YYYY-MM&from=share&card=budget-kept`
- 埋点：`budget.kept.share`、`budget.kept.view`

## 异常兜底

- 有任一品类超预算 → 不触发该卡片；走 "budget-alert"（预算预警，由消息侧承接，不在本卡片范围）
- 无预算设置 → 不触发；首页引导 CTA → `pages-stat/budget-setup`
