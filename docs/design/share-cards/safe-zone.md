# 分享卡片 · 通用安全区 v0.1

> **卡号**: COSTRA-011（Round-2） · **关联**: [`README.md`](./README.md) P1-2

---

## 1. 为什么需要"安全区"

微信小程序分享到**单聊/群聊**与**朋友圈**时，系统会：

1. 在卡片**顶部**叠加发送者信息条（头像 + 昵称，约 80rpx 高）；
2. 在卡片**底部**叠加小程序名片（图标 + 名称，约 100rpx 高）；
3. 朋友圈分享触发 `onShareTimeline` 时，还会在**左右两侧**做 ~16rpx 内边距裁切。

若视觉关键元素（标题、核心数字、CTA）放在这些区域，会被遮挡 / 裁切，导致"分享出去看不到重点"。

---

## 2. 统一安全区规范（4 张卡片全部遵守）

```
┌──────────────────────────────────────────────┐  ← 卡片外框 (radius.lg 12rpx)
│  ▒▒▒▒ 顶部外部遮挡区（不可放关键信息） ▒▒▒▒  │  ← 0 ~ 64rpx
│                                              │
│  ┌────────────────────────────────────────┐  │  ← 安全区起点
│  │                                        │  │
│  │         关键标题 / 核心数字            │  │
│  │         主插画 / 图表                  │  │
│  │                                        │  │
│  └────────────────────────────────────────┘  │  ← 安全区终点
│                                              │
│  ▒▒▒▒ 底部外部遮挡区（仅放品牌署名） ▒▒▒▒   │  ← 画布高 - 64rpx ~ 画布高
└──────────────────────────────────────────────┘
    ↑ 左 32rpx       右 32rpx ↑
```

| 区域 | 规则 | 可放内容 |
|---|---|---|
| **顶部安全边距** | ≥ **64rpx** | 装饰背景、渐变、禁止关键字 |
| **底部安全边距** | ≥ **64rpx** | 仅 Costra 品牌署名（右下角，对齐 README §1） |
| **左右安全边距** | ≥ **32rpx** | 装饰渐变；关键字左右再额外缩进 8rpx |
| **关键元素区** | 画布尺寸 -（64+64+32+32）| 标题、核心数字、主插画、CTA |

---

## 3. 画布尺寸与安全区实测

以 README §1 约定的 **750 × 600 rpx** 画布为例：

```
画布           : 750 × 600
外边距         : 上/下 64 / 左/右 32
关键元素区     : (750 - 32*2) × (600 - 64*2) = 686 × 472
```

对 4 张卡片的具体应用：

| 卡片 | 画布 | 关键区 | 备注 |
|---|---|---|---|
| family-invite | 750 × 600 | 686 × 472 | 标题 + 昵称 + 邀请码徽章 |
| annual-report | 750 × 937（3:4） | 686 × 809 | 朋友圈分享建议改此比 |
| entry-flex | 750 × 600 | 686 × 472 | 居中金额放关键区上半 |
| budget-kept | 750 × 750（1:1） | 686 × 622 | 成就徽章置于关键区中心 |

## 4. 校验清单（产出 .png 前自查）

- [ ] 距顶 64rpx 内只有渐变/装饰背景，无文字和金额
- [ ] 距底 64rpx 内仅右下角品牌署名（可左对齐右对齐任选一，全卡片内统一）
- [ ] 左右 32rpx 内无关键信息
- [ ] 所有文本对比度 ≥ 3:1（大字）/ 4.5:1（正文），参见 `docs/design/a11y/contrast-report.md`
- [ ] 无诱导分享话术（"点击分享领红包"等）
- [ ] 无二维码悬浮在缩略图上（微信规范禁止）

## 5. 技术承接

- 合成脚本路径：`miniprogram/services/share-card-composer.ts`（Sprint-3 落地）
- 在 Canvas 绘制前，统一 `ctx.save() + ctx.translate(32, 64)`，并将画布尺寸限制为安全区尺寸
- 静态兜底图（`miniprogram/tokens/share-cards/*.png`）由设计师产出时已按本规范裁切，MiniApp 层不再做额外 padding
