## 0. TL;DR（10 分钟看完）

- **什么是 ICP 备案**：在中国大陆境内提供服务的网站/小程序后端域名，必须完成**工信部 ICP 备案**（《互联网信息服务管理办法》强制要求）。
- **为什么现在就做**：Costra 后端 `api.costra.xxx` 需配到微信小程序"服务器域名白名单"；而小程序白名单**要求域名已完成 ICP 备案**。审核周期 **10~20 个工作日**（各省管局不同），是整个发布链路最长的一根。
- **怎么做（三句话）**：
  1. 先在云厂商买**大陆节点的 ECS / 轻量服务器**（阿里云 / 腾讯云 / 华为云任选），再买域名；
  2. 在云厂商控制台"**ICP 备案系统**"提交资料 → 云厂商初审（1~3 天）→ 工信部短信核验 → 通信管理局终审（10~20 工作日）；
  3. 拿到备案号（形如 `粤ICP备2026xxxxxx号`）后，域名解析到服务器 + 配 HTTPS，再把域名贴进微信小程序后台"服务器域名"。
- **本周目标**：今日（2026-04-22）**完成资料收集并在云厂商提交初审**，D+20（约 2026-05-22 前）拿到备案号。

## 1. 备案主体决策（⚠️ 先决定这一步）

Costra charter §7 描述为"内部研发"，但微信小程序类目 **"生活 → 记账工具"** 强制要求**企业主体**（charter §9 已标注"企业主体认证 ⏳ 待 Human"）。两件事结论一致：**必须用企业主体**。

| 维度 | 企业主体（推荐） | 个人主体（不可行） |
|---|---|---|
| 微信小程序记账类目 | ✅ 允许 | ❌ 驳回 |
| ICP 备案 | 企业备案 | 个人备案，但**禁止用于经营性/涉及他人资金的服务** |
| 备案数量 | 一个主体可备多个域名（无硬性上限） | 一般 1~2 个 |
| 所需材料 | 营业执照 + 法人身份证 + 网站负责人身份证 | 身份证 + 手持照 |
| **Costra 结论** | ✅ **采用** | ❌ 不采用 |

**动作**：
- 若 **steve 已有公司**：直接用该公司营业执照即可，跳到 §3。
- 若 **尚无公司**：走"个体工商户"最快（线上 1~3 工作日，各地电子营业执照 APP 可办），**不要**用"个人主体"强行备案后商用，后续会被抽查驳回并连累小程序过审（charter §11 R-001）。

## 2. 前置条件清单（Pre-flight Checklist）

进入云厂商备案系统前，以下**全部**需就绪，否则中途会卡住重来：

### 2.1 基础资源（必须先买好）
- [ ] **大陆节点服务器**：阿里云 / 腾讯云 / 华为云 任选其一
  - 规格：轻量 2C2G 起（备案期间只需"能解析到一台大陆 IP"即可，后续再升配）
  - 地域：**必须大陆**（香港/新加坡/海外节点**不能**用于 ICP 备案）
  - 时长：**购买 ≥ 3 个月**（各省管局硬门槛，1 个月的不受理）
  - Costra 推荐：**腾讯云轻量应用服务器 2C2G 3M 3 年版**（与微信生态顺滑，备案入口在一个控制台）
- [ ] **域名**：在**同一家云厂商**买（跨厂商备案流程会更麻烦）
  - 推荐：`costra.xxx`（根域名用于官网跳转页，子域名 `api.` / `ws.` 服务小程序）
  - 后缀：`.com` / `.cn` / `.net` 均可；**避免** `.top` `.xyz` 等已被部分管局列入慎用名单的后缀
  - 命名需**可备案**：含"记账"关键词不冲突；避免含 `bank/pay/finance/invest` 等金融敏感词（charter 已明确记账非金融类目）
- [ ] **域名实名认证已完成**：买完域名后立即在域名控制台做实名认证（用企业主体），**等待 3~5 个自然日**让实名信息入库——**这一步经常被忽视，是最常见的备案被退原因**

### 2.2 材料（拍照/扫描件，JPG/PNG，每张 < 4MB）
- [ ] 营业执照（**彩色扫描件**，有效期 ≥ 3 个月）
- [ ] 法人身份证（正反面）
- [ ] **网站负责人身份证**（正反面）— 可以是法人本人
- [ ] 网站负责人手机号（**必须已三要素实名**）+ 邮箱
- [ ] 办公/注册地址详细信息（市/区/街道/门牌号，与营业执照一致）
- [ ] 应急联系人手机号（可与负责人同号）
- [ ] （部分省份要求）**法人手持营业执照原件照片** 或 **网站负责人手持身份证照片**
- [ ] **幕布照**：由云厂商**免费寄送**（蓝底白字"阿里云/腾讯云专用幕布"），人站在幕布前拍照；**现在就申请寄送**，快递 2~4 天，否则后面卡这里
- [ ] **域名证书**（域名控制台一键下载 PDF）
- [ ] 《**互联网信息服务备案承诺书**》：云厂商模板里下载 → 打印 → 法人签字 + 盖公章 → 扫描回传

### 2.3 合规信息（备案表单要填，提前想好）
- [ ] **网站名称**：建议填 `Costra 家庭记账`（**不能**含"中国/官方/第一/最"等敏感词；**不能**是纯域名）
- [ ] **网站服务内容**：勾选"**其他 → 家庭内部记账工具**"（不要勾"金融""支付""理财"，会触发前置审批驳回）
- [ ] **小程序类目对应**：备案里没有独立小程序类目，仍按"网站"提交即可；微信侧类目已定（生活 → 记账工具）
- [ ] **域名用途**：`api.costra.xxx` 填"小程序后端 API"；`ws.costra.xxx` 填"实时消息推送 WebSocket"；主域名 `costra.xxx` 填"产品官网"
- [ ] 是否涉及前置审批：**否**（记账工具不涉及新闻/出版/教育/医疗/文化/广电/药品 7 类前置）

## 3. 备案全流程（以腾讯云为例，阿里云 95% 类同）

```
D0  今日
 ├─ Step 1: 买服务器 + 买域名（同一账号，同一主体）
 ├─ Step 2: 域名实名认证 ──────────┐
 │                                 │ 等 3~5 天入库
D+3                                │
 ├─ Step 3: 申请寄送幕布           │
 ├─ Step 4: 进入备案系统填资料 ←──┘
 │         ↓
 │  Step 5: 云厂商初审（1~3 工作日）
 │         ↓ 通过
 │  Step 6: 工信部短信核验（24 小时内完成，必做）
 │         ↓
 │  Step 7: 通信管理局终审（10~20 工作日）
D+20±
 └─ Step 8: 下号 → 配 HTTPS → 小程序白名单 → DONE ✅
```

### Step 1 · 购买服务器 + 域名（今日 30 分钟）
1. 登录 https://console.cloud.tencent.com/ （或阿里云）
2. 购买**轻量应用服务器**：北京/上海/广州任一大陆节点，**3 个月起**
3. 购买**域名**：`costra.com`（示例）→ 选"企业"主体 → 填公司信息
4. **立即做域名实名认证**（控制台 → 域名 → 实名认证 → 上传营业执照）

### Step 2 · 等待实名入库（D+3~D+5）
- 实名成功后**不能立即备案**，CNNIC 要 3 个自然日同步数据到备案系统
- 这期间做 Step 3

### Step 3 · 申请幕布（D+0 就能申请）
- 腾讯云：控制台 → 备案 → "申请幕布"→ 填寄送地址 → 2~4 天到货
- 到货后拍幕布照（要求：人像完整、幕布 Logo 清晰、光线充足、不能 PS）

### Step 4 · 填备案资料（D+5，约 1 小时）
- 入口：https://console.cloud.tencent.com/beian
- 依次填：
  1. 主办单位信息（企业名 / 统一社会信用代码 / 注册地址 / 法人）
  2. 网站负责人信息（身份证 / 手机 / 邮箱 / 应急联系人）
  3. 网站信息（网站名 / 域名 / 服务内容 / 语言：简体中文）
  4. 上传所有 §2.2 材料
- **⚠️ 高频坑**：
  - 负责人手机号必须能收短信（工信部短信核验 24 小时不回会退回）
  - 地址要**精确到门牌号**，"XX 写字楼 A 座"不够，需"A 座 1801 室"
  - 网站名**避免**"投资/理财/基金/支付/收款"字样

### Step 5 · 云厂商初审（D+5 ~ D+8）
- 客服会电话核实：打给网站负责人，问"网站做什么用？是否合法合规？"
- **标准话术**：
  > "这是家庭记账工具小程序的后端服务域名，仅供家庭成员内部记录消费流水，不涉及任何资金清算、第三方支付、理财投资。"
- 接不到电话会退回，**D+5 开始保持手机畅通 3 天**

### Step 6 · 工信部短信核验（云厂商通过后 24 小时内）
- 收到短信后**打开链接，人脸识别**（法人 + 负责人各自一次，若同人则一次）
- **超时 24 小时**备案作废，从 Step 4 重来——**这是最痛的坑，单独设个闹钟**

### Step 7 · 通信管理局终审（D+8 ~ D+20+）
- 省级管局审核，**10~20 工作日**，Costra 按广东/北京粗估 **15 工作日**
- 这期间**不要**改域名解析、不要关服务器、不要转移域名
- 可以登录备案系统看进度："管局审核中"→"管局审核通过"

### Step 8 · 下号（D+20±）
- 收到短信："您的备案已通过，备案号 `粤ICP备2026xxxxxx号`"
- 备案号**必须**公示在网站底部 & 小程序"关于我们"页（合规要求，QA-Agent 会查）
- 此时才能：
  1. 在域名解析添加 A 记录指向服务器 IP
  2. 配置 HTTPS（免费走 Let's Encrypt 或云厂商免费 DV 证书）
  3. 登录 https://mp.weixin.qq.com → 开发 → 开发管理 → 开发设置 → 服务器域名 → 添加 `api.costra.com` / `wss://ws.costra.com`
  4. 通知 Backend-Agent 和 DevOps-Agent：COSTRA-040 真实链路可以激活了

## 5. 常见退回原因 Top 10（提前规避）

| # | 原因 | 规避 |
|---|---|---|
| 1 | 域名未实名 / 实名未入库就提交 | §2.1 Step 2 等满 3 天 |
| 2 | 服务器购买时长 < 3 个月 | 一次买 3 个月以上 |
| 3 | 网站负责人手机号非本人实名 | 用法人/负责人本人号 |
| 4 | 短信核验超时 24 小时 | 设闹钟，收到立即做 |
| 5 | 网站名含"金融/理财/支付/投资" | Costra 统一用"家庭记账"表述 |
| 6 | 幕布照片 PS / 非官方幕布 | 必须用云厂商寄的实体幕布 |
| 7 | 地址不精确 | 精确到室/门牌号 |
| 8 | 服务内容描述过于笼统（如"网站建设"） | 写清"家庭内部记账工具小程序后端服务" |
| 9 | 营业执照过期 / 模糊 | 重新扫描，清晰可读 |
| 10 | 法人/负责人近 30 天有其他备案在审 | 错峰，或换另一位负责人 |
