# Costra 项目章程（Charter）

> 这是 Orchestrator 与 PM-Agent 的"第一输入"。Human 填完此文档后，Sprint-0 才真正开始。

## 1. 项目名与寓意
**Costra** = cost + track，面向家庭的云端共享记账 iOS App。

## 2. 愿景
让一个家庭在同一本账上安心协作记账：数据安全、实时同步、看得懂、用得爽。

## 3. 北极星指标（北极 KPI）
- D1 留存 ≥ 40%
- 家庭激活率（3+ 成员） ≥ 15%
- 月人均记账次数 ≥ 30

## 4. MVP 范围（Must-Have）
- [M] 账号体系（手机号 + Apple ID）
- [M] 单人记账（账户 / 分类 / 流水 / 基础统计）
- [M] 本地离线 + 云端增量同步
- [M] 家庭创建 / 邀请 / 成员权限
- [M] 实时变更推送
- [M] 隐私合规（iOS 隐私清单 / ICP 备案）

## 5. 暂不做（Won't-Have · 首版）
- AI 语音记账
- 账单 OCR
- Apple Watch / 灵动岛扩展
- 端到端加密账本

## 6. 成功标准
- App Store 审核一次通过
- 生产 SLA ≥ 99.9%
- P0 缺陷清零
- 发布后首周家庭创建数 ≥ 1000

## 7. 约束
- 预算：内部研发
- 团队：7 个 Agent（含 Orchestrator）+ 1 位 Human（你）
- 时长：目标 6~9 个月至正式上线
