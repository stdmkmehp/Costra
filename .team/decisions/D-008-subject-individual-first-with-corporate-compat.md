## 🎯 决议（一句话）

> **MVP 阶段以个人主体完成 ICP 备案、小程序提审、上线跑通；程序与合规产物必须在"主体可替换"的前提下编写，使日后迁移到公司主体时，代码不需要结构性修改，仅替换配置 / 文案 / 备案号即可。**

## 🧭 背景

- 公司主体路径需要财务 / 法务配合（营业执照、对公账户打款验证、法人人脸核身、电子签章），目前两岗位人力缺失；
- ICP 备案（20 工作日关键路径）不能继续等人力补齐，否则堵死 Sprint-2 的真实上线节奏；
- 小程序审核流程允许个人主体先上线 MVP，后续通过"开发者主体变更"流程迁移到公司主体（需重新走一次审核 + 域名 ICP 主体变更）。

## ✅ 立即生效的工程约束（Sprint-1 起）

### 1. 代码层面：禁止任何硬编码主体/备案/联系信息

所有"主体相关常量"必须集中配置，**严禁散落在业务代码、模板字符串、分享卡片、订阅消息文案中**。

| 位置 | 要求 |
|---|---|
| `miniprogram/config/subject.ts`（**新建**） | 导出 `SUBJECT_NAME` / `SUBJECT_TYPE`（`"individual" \| "corporate"`）/ `ICP_NUMBER` / `CONTACT_EMAIL` / `PRIVACY_EFFECTIVE_DATE` |
| `server/src/config/subject.ts`（**新建**） | 同上字段的后端副本，读自 `.env` |
| `.env.production.example` | 新增 `SUBJECT_*` 段，个人版与公司版各一套示例，注释说明切换方式 |
| 隐私指引 / 用户协议 / 关于页 | 全部通过**模板变量**渲染，禁止写死主体名 |
| 分享卡片 / 订阅消息文案 | 禁止出现"由 XX 公司提供"这类硬编码表述；主体字样一律走 `SUBJECT_NAME` |

### 2. 数据库层面：不引入主体耦合

- `users` / `entries` 等表**不得**存"主体 ID"；
- 审计日志（Epic-D 的 audit_log）记录的"数据控制者"字段走配置读取，不建外键；
- 迁移脚本不得假设主体类型。

### 3. 合规产物：主体可替换字段集中标注

- `docs/ops/privacy-guideline.md`（COSTRA-109 即将产出） → PM 必须把"主体名称 / ICP 号 / 联系方式 / 数据控制者"四项标注为 `{{SUBJECT_*}}` 占位，附一张"个人 → 公司切换对照表"；
- `docs/qa/wechat-review-checklist.md` → 新增"主体切换专项自查"一节；
- `docs/ops/subject-compat-matrix.md`（**新建**，由 PM 起草，COSTRA-111 派单） → 列出**所有涉及主体字样的文件/字段/页面**，作为未来切换时的一次性检查清单。

### 4. 微信侧资源：按个人主体申请，但保留切换路径

| 资源 | MVP（个人） | 未来（公司） | 切换成本 |
|---|---|---|---|
| 小程序 AppID | 当前 `wxf8b0d3e3a83f9941`（个人） | 新申请公司号 **或** 走"开发者主体变更"流程 | 变更流程官方支持，需重新审核一次 |
| ICP 备案 | **个人主体备案**（Human 身份证） | 申请"主体变更"或新备案 | 20 工作日 |
| 小程序类目 | 生活 → 记账工具（无资质要求） | 不变 | 零成本 |
| 订阅消息模板 | 个人主体申请 3 条 | 切号后需在新号重新申请 | 1~3 日审核 |
| 对外名称 "Costra" | 保留 | 保留 | 零成本 |
| 支付能力 | ❌ **MVP 不接入**（个人号不支持微信支付商户） | 开通商户号 | 见下方 §刻意排除 |

### 5. 刻意排除（Won't-Have，写入 PRD 边界）

以下能力在个人主体阶段**严禁纳入**，避免未来切换时出现"无法迁移"的硬骨头：

- ❌ 微信支付 / 微信商户号接入（含任何"收款/打赏/订阅付费"功能）
- ❌ 虚拟支付（iOS 合规风险，小程序同源）
- ❌ 需要"企业认证"才能开通的接口（如：发货信息录入、交易组件、视频号转化追踪）
- ❌ 需要对公打款验证的任何第三方 SDK

如 Sprint-3+ 出现上述需求，**必须先完成主体迁移，再启动该需求**。

**R-014** · 主体切换债务累积（🟠）
- **描述**：若 Sprint-3+ 不定期扫描硬编码主体字样，切换时将付出远超预期的工程成本。

- **缓解**：COSTRA-050 审核自查清单新增"个人主体文案禁区"条目。

**R-013 补丁**：域名决策时效从"ICP 受理后 7 日内"**提前到"今日/本周内"**，因为个人备案一旦启动即立刻进入"无域名不可提交"状态。
