## 附录 A · 小程序《用户隐私保护指引》模板官方获取路径

**权威来源（按优先级）**：

1. **微信官方小程序后台（强烈推荐）**
   - 地址：https://mp.weixin.qq.com
   - 路径：登录 → **「设置」→「服务内容声明」→「用户隐私保护指引」→「编辑并填写」**
   - 后台会直接给你一个**在线表单 + 官方模板文案**，按 checkbox 勾选处理的用户信息、填主体名称与邮箱即可，系统自动生成合规文本，免去格式错漏。

   - 配合阅读：**《用户隐私保护指引内容要点》**
   - 该页包含官方模板的 JSON 结构、每个字段的填写示例、以及 2023-09 后强制的 `__wxPrivacyConfig` 配置方式。

## 附录 B · ADR-0002 补丁：后端部署平台决策

> 追加到 `.team/decisions/ADR-0002-tech-stack.md` §部署 末尾（Orchestrator 将在登记 D-007 的同时执行此追加；若 ADR-0002 缺失该小节则新增）。

### 决策

- **最终平台**：**延后至 Sprint-2 末再拍板**。
- **Sprint-1 & Sprint-2 的工作约束**：
  - 后端、前端、基础设施（PostgreSQL / Redis）全部通过 **docker 镜像 + docker-compose** 交付。
  - `server/Dockerfile` 必须支持 **linux/amd64 与 linux/arm64 双架构**（未来可能落到腾讯云 ARM 机或微信云托管）。
  - 环境变量一律通过 `.env.production.example` 声明，不写死任何云厂商专有变量。
  - 禁止在 `docker-compose.yml` 出现 host volume 路径依赖（只允许具名 volume）。
- **候选方案（届时再选）**：腾讯云 Lighthouse / 微信云托管 / 阿里云 ECS / 自建。
- **触发再决策的条件**：ICP 备案下证 OR Sprint-2 开始前 5 天（两者取早）。

### 理由

- 避免过早绑定云厂商导致返工。
- docker 镜像是"平台中立的最小公分母"，任意容器/容器服务/云托管/虚机都能直接跑。
- 与 Sprint-1 既定的 docker-compose 本地开发路径完全对齐，零额外成本。
