# COSTRA-104 R1.x.1 · dev WX mock 入口 · 2026-05-12

## §1 任务概述

Human curl 实测发现 `npm run dev` 默认走真实腾讯 code2Session · 用假 code（如 `test-curl-verify`）被腾讯返 `40029 invalid code` · 联调无法继续。

**修复**：加 dev 专用 `WX_MOCK_LOGIN=1` 开关 · 启动期注入硬编码 mock fetch · 任意 code 返成功响应。

## §2 交付物

| 文件 | 改动 |
|---|---|
| `server/src/config/env.ts` | AppEnv 加 `wxMockLogin: boolean` + `parseBool()` helper + loadEnv 内 dev-only 校验 throw |
| `server/src/server.ts` | main() 启动期 `setWxFetchForTests()` 注入 mock fetch + listen 后 warn 日志 |
| `server/.env.example` | WX_APP_SECRET 后追加注释样例 `# WX_MOCK_LOGIN=1` |
| `docs/qa/costra-104-curl-verify.md` | v1.1 → v1.2：插 §0.2 dev mock 启动方式 + 修订记录 |

## §3 闸门

- `npm run typecheck` → 0 错 ✅
- `npm run test` → 20/20 全绿 ✅
- `NODE_ENV=production WX_MOCK_LOGIN=1 loadEnv()` → throw `[env] WX_MOCK_LOGIN can only be enabled in NODE_ENV=development` ✅

## §4 prod 安全保护（最关键）

env.ts loadEnv return 前加校验：
```ts
if (cfg.wxMockLogin && cfg.nodeEnv !== 'development') {
  throw new Error('[env] WX_MOCK_LOGIN can only be enabled in NODE_ENV=development');
}
```
→ 确保 prod/test 误开立即 crash · 永不暴露到生产。
