### B. 用户隐私保护指引

- [x] `miniprogram/pages-family/privacy/index.wxml` 已补全完整法律条款（COSTRA-901）
- [x] `app.json` 已声明 `requiredPrivateInfos: ["chooseAvatar", "nickname"]`（COSTRA-901）
- [x] 隐私弹窗已实装：`app.ts` 注册 `wx.onNeedPrivacyAuthorization`，首次触发隐私接口前弹出授权确认（COSTRA-901）
- [x] 拒绝授权后降级只读演示模式（`globalData.privacyAuthorized = 'denied'`）

- [ ] **【提审前 Human 确认】** 隐私指引内容与代码实际行为已人工交叉核对（收集字段、使用目的、共享规则）
- [x] 不在用户未授权前静默调用用户画像相关接口（`wx.login` 仅做身份验证，不关联 userInfo）

### C. 头像昵称新规（2023-09 起）

- [x] 未使用 `wx.getUserProfile`（已废弃）
- [x] 头像选择使用 `<button open-type="chooseAvatar">`（`pages/profile-setup/index.wxml`）
- [x] 昵称输入使用 `<input type="nickname">`（`pages/profile-setup/index.wxml`）
- [x] 头像上传到自建服务端 `POST /v1/upload/avatar`，返回持久 URL（已在隐私指引中声明）
- [x] 昵称输入框无预填微信昵称（`nickname === '微信用户'` 时清空显示）

### D. 订阅消息

- [ ] **【Epic-D/E 前不涉及，标记 N/A】** 模板 ID 申请（预算预警/家庭邀请/周报摘要）— Sprint-7 再勾选
- [x] 当前版本未调用 `wx.requestSubscribeMessage`，本项暂不适用

### E. 分享与诱导分享

- [x] 邀请卡片文案已审查：无"点击领取"/"必得"等诱导词
- [x] 分享功能仅用于家庭成员邀请（功能性分享，非营销诱导）
- [x] 无 webview 指向未备案外部域名
- [ ] **【提审前 QA 确认】** 所有分享卡片变体（share_card_variant A/B）已人工审核文案

### F. 账号与登录

- [x] 微信一键登录（`wx.login` → code2Session），无第三方账号体系
- [x] Token 不入日志、不拼接到 URL 参数（`services/auth.ts` + `services/request.ts`）
- [x] 未登录状态 → 强制跳转 `pages/login/index`，无法访问任何数据页面
- [x] 隐私协议拒绝后降级只读演示，不写入用户数据

### G. 支付与虚拟物品

- [x] 当前版本**不涉及**任何支付功能（个人主体阶段 Won't-Have，见 D-008）
- [x] 不收集银行卡号、身份证号
- [x] 无虚拟物品购买、无内购、无充值

### H. 广告与营销

- [x] 无广告 SDK 接入
- [x] 无积分/签到/裂变等营销机制
- [x] 应用内文案无夸大宣传（"家庭记账"表述准确）

### I. 数据存储与安全

- [x] 所有 API 通信走 HTTPS（`costra.cloud`，证书有效）
- [x] Token 存储于 `wx.setStorageSync`（微信沙盒，不出域）
- [x] 后端数据存储于国内服务器，不出境
- [x] 账单数据仅用户本人及明确邀请的家庭成员可见（服务端鉴权）
- [x] 公安联网备案已提交（2026-05-19，预计 2026-06-09 下证）

### J. 域名与服务器配置

- [x] 生产 API 域名 `costra.cloud` 已 ICP 备案（沪ICP备2026017253号-2）
