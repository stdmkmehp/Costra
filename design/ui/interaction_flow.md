# Costra - 交互流程说明 (Interaction Flow)

## 1. 登录流程 (Login Flow)
*   **触发条件**：用户首次打开小程序，或主动退出登录后。
*   **界面表现**：全屏暖灰白背景，居中显示品牌 Wordmark 及随机记账格言。
*   **操作与反馈**：
    *   点击底部 [微信一键登录] 按钮。
    *   唤起微信原生授权底部弹窗 (ActionSheet)。
    *   用户同意后，按钮呈现加载状态 (Loading Spinner)，成功后页面淡出 (Fade out)，直接进入【明细页】。

## 2. 核心记账流程 (Add Expense Flow) - 极速模式
*   **触发条件**：用户在任何非登录页面，点击 TabBar 正中间的 `[+]`。
*   **界面表现**：
    *   **初始状态**：不发生页面路由跳转。全屏铺满“分类网格”。顶部有弱化的“支出/收入”滑动指示器。
*   **操作与反馈 (Step-by-Step)**：
    1.  **选择分类**：用户点击网格中的某个分类图标（如“餐饮”）。
    2.  **界面动态 (分类交互与键盘升起)**：
        *   **场景 A (点击上方的一级分类，如“餐饮”)**：
            *   该“餐饮”图标平滑移动至屏幕上半部的安全区。
            *   **同级弱化**：未被选中的其他一级分类（如交通、生活）透明度降至 0.2，产生明显的层级沉浸感（底色依然为暖灰白 `#f1f2ec`）。
            *   **二级展开与默认选中**：在“餐饮”下方原地展开其所有的二级分类（如餐饮、外卖、买菜），并**自动默认选中**第一个同名子分类“餐饮”（呈现高亮）。
            *   **键盘升起**：从屏幕底部丝滑升起包含“金额栏/备注/数字键盘”的交互面板。
        *   **场景 B (越过一级，直接点击下方的二级分类，如“机票”)**：
            *   **越级直选与去重逻辑**：全屏网格展示时，系统会自动对分属于不同一级分类的同名二级分类（如“旅行”下的“机票”与“交通”下的“机票”）进行视觉去重，确保网格中同一名称的二级分类只出现一次。
            *   **智能归属**：用户直接点击该去重后的二级图标时，系统根据底层数据字典的权重配置，将其默认归属于某个一级分类（例如，直接点击“机票”，系统记录为“交通-机票”，而非“旅行-机票”）。不引发界面一级分类的反推与展开，避免大幅度跳跃。
            *   **智能防遮挡**：判断该图标位置。若其位于下半屏，整体网格自动向上平滑滚动 (Scroll-to-view)，确保其移至上半屏可视区。
            *   **键盘升起**：底部交互面板升起。
    3.  **输入金额 (算式展示)**：用户在数字键盘点击 `1`, `2`, `+`, `8`。屏幕中部的金额大字区实时显示 `12 + 8`，此时键盘右下角核心按钮显示为 `[=]`。
    4.  **计算结果**：用户点击 `[=]`。系统计算并在金额区显示结果 `20`。同时，右下角核心按钮的状态和文案从 `[=]` 变为绿色的 `[完成]`。
    5.  **保存账单**：用户确认无误后，点击 `[完成]` 按钮。
    6.  **结束动态**：系统将 `20` 保存到当前账本。底部数字键盘及全屏分类网格向下收起 (Slide down)，返回点击 `[+]` 前的界面。界面中央弹出原生的轻提示 (Toast)：`记账成功`。

## 3. 记账附加操作 (Add Expense - Edge Cases)
### 3.1 添加备注
*   在键盘弹出的状态下，用户点击金额栏下方的“添加备注...”文本框。
*   **反馈**：底部的自定义数字键盘隐藏，**原生系统输入法键盘**弹出。用户输入文本后点击键盘上的“确定”或空白处，系统键盘隐藏，数字键盘重新弹出恢复原状。
### 3.2 切换账本归属
*   在“添加备注...”文本框左侧，点击 `[记入: 我的账本 ▼]`。
*   **反馈**：唤起微信原生底部 ActionSheet，列出用户所属的所有账本（单人/家庭）。点击选择后，小标签文字更新。
### 3.3 切换收入/支出
*   在初始全屏分类状态下，或者键盘弹出的状态下，用户手指在分类网格区域**水平向左/向右滑动**。
*   **反馈**：分类面板像相册一样翻页，平滑切换到“收入”类的图标网格。

## 4. 明细页流转 (Ledger Flow)
*   **状态表现**：进入后首屏，向下滑动时，当前日期的 Header 会**吸顶**。
*   **账本切换**：点击顶部 Navigation Bar 中央的 `[我的账本 ▼]`。
    *   **反馈**：弹出原生 ActionSheet。选择其他家庭账本后，明细列表数据原地刷新 (无页面跳转白屏)。
*   **月份切换**：点击右上角汇总区的 `[2026年5月 ▼]`。
    *   **反馈**：唤出原生底部日期滚轮 (`<picker>`)。确定后刷新数据。
*   **单条记录操作 (隐性操作)**：
    *   在单条流水上**向左滑动**。
    *   **反馈**：滑出红色的 `[删除]` 操作块。点击确认后该条目消失，并伴随微信触觉震动 (Haptic)。

## 5. 统计页流转 (Statistics Flow)
*   **成员维度比对 (Swipe for Members)**：
    *   在多人家庭账本的统计页内容区**水平向左/向右滑动**。
    *   **反馈**：页面像相册一样横向翻页，在 `[全部]`, `[自己]`, `[成员A]` 等不同数据主体间平滑切换。顶部对应的成员指示器随之高亮。此设计极大优化了家庭成员间的查账与数据比对效率。单人账本下无此交互。
*   **时间维度切换 (Click for Time)**：
    *   点击顶部极简的 `[月度 | 年度]` 按钮。
    *   **反馈**：当前成员的数据瀑布流原地刷新，在月度与年度排版架构间切换。
    *   点击时间选择器两侧的 `[<]` 或 `[>]` 箭头。
    *   **反馈**：页面数据平滑刷新为上一个/下一个时间周期的数据。
*   **分类数据下钻 (Drill-down)**：
    *   在下方的分类排行榜中，点击任意一行**一级分类**（如“交通”）。
    *   **反馈**：该行向下**手风琴式展开 (Accordion Expand)**，无缝渲染出该一级分类下的所有二级分类明细列表及金额。再次点击该一级分类则收起。不发生页面路由跳转。
*   **年度流水穿梭 (Annual to Monthly)**：
    *   在“年度视角”的月度流水列表中，点击特定的某个月份（如“8月”）。
    *   **反馈**：视图自动平滑切换回“月度视角”，并且时间上下文自动设定为用户刚刚点击的“8月”。

## 6. 家庭页流转 (Family Flow)
*   **邀请成员**：
    *   点击横排头像末尾的 `[+]`。
    *   **反馈**：拉起微信原生“发送给朋友”组件。
*   **管理成员 (仅创建者)**：
    *   点击横排中的其他成员头像。
    *   **反馈**：底部弹出原生 ActionSheet，含红色的 `[移出家庭]` 选项。
*   **维度与时间切换**：
    *   点击进度条区域的 `月度 / 年度` 文本，或点击上方 `[<] [>]` 箭头。
    *   **反馈**：进度条及其上方的数据原地刷新重绘。

*   **公共/个人数据下钻 (Data Drill-down)**：
    *   在下方的收支明细列表中，点击任意一行（如“公共支出”或某个成员的“个人支出”）。
    *   **反馈**：该行向下**手风琴式展开**，平铺渲染出该归属板块下金额最高的几项分类支出明细排行。再次点击该行则收起。

## 7. 我的页面 (Profile Flow)
*   基本为静态的信息展示。点击分组卡片中的条目（如“导出数据”）会执行常规的向左推入 (Push) 页面跳转。
